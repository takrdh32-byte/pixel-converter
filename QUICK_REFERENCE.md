## 📋 Checklist:

```
⏱️ 5 Minutes में:

⬜ 1. GitHub Account बनाओ (2 min)
⬜ 2. Repository बनाओ (1 min)

⬜ 4. GitHub Pages Enable करो (1 min)
✅ DONE! Live हो गया!
```

---

## Step-by-Step Process:

### **Step 1️⃣: GitHub Account (2 मिनट)**

```
Browser खोलो
    ↓
https://github.com/signup जाओ
    ↓
Email डालो
    ↓
Password बनाओ
    ↓
Username चुनो
    ↓
Email verify करो
    ↓
✅ Account Ready!
```

---

### **Step 2️⃣: Repository बनाओ (1 मिनट)**

```
GitHub पर लॉगिन करो
    ↓
Profile icon (top right)
    ↓
"Your repositories"
    ↓
"New" button
    ↓
Details भरो:
├─ Name: pixel-converter
├─ Description: Image Resizer & Converter
├─ Public: ✓ (जरूर check करो)
└─ Add README: ✓
    ↓
"Create repository"
    ↓
✅ Repository Ready!
```

---

### **Step 3️⃣: Files Upload (1 मिनट)**

**Option A: GitHub Web Interface**

```
Repository खोलो
    ↓
"Add file" button (top right)
    ↓
"Create new file"
    ↓
Name: index.html
    ↓
Content paste करो (नीचे के text area में)
    ↓
"Commit changes"
    ↓
Repeat for:
├─ style.css
└─ script.js
    ↓
✅ Files Uploaded!
```

**Option B: Drag & Drop (अगर possible हो)**

```
Repository खोलो
    ↓
3 files को drag करके repo पर drop करो
    ↓
Commit करो
    ↓
✅ Files Uploaded!
```

---

### **Step 4️⃣: GitHub Pages Enable (1 मिनट)**

```
Repository Settings
    ↓
बाईं ओर "Pages" ढूंढो
    ↓
Source: "Deploy from a branch"
    ↓
Branch: main
    ↓
Folder: /root (or .)
    ↓
"Save" करो
    ↓
1-2 मिनट इंतज़ार करो
    ↓
✅ Website LIVE!
```

## 🐛 Problem Troubleshooting:

### ❌ Problem: Website नहीं खुल रही

```
✓ Check: GitHub Pages enabled?
✓ Check: 2 minutes हो गए?
✓ Check: Branch = main?
✓ Check: Files सही folder में हैं?
✓ Try: Hard refresh (Ctrl+Shift+R)
```

### ❌ Problem: Styles नहीं आ रहे

```
✓ Check: style.css file uploaded?
✓ Check: Filename exactly "style.css"?
✓ Check: HTML में link सही है?
✓ Try: Browser cache clear करो
```

### ❌ Problem: JavaScript काम नहीं कर रहा

```
✓ Check: script.js file uploaded?
✓ Check: Filename exactly "script.js"?
✓ Check: HTML में script tag सही है?
✓ Try: Browser console देखो (F12)
```

## 📞 Common Questions:

### Q: Domain change करना चाहता हूँ
A: Settings → Pages → Custom domain (अगर domain खरीदा हो)

### Q: Private repository बनाऊँ?
A: Nope! GitHub Pages के लिए public होना ज़रूरी है

### Q: एक बार में 2-3 files upload कर सकता हूँ?
A: Drag & drop से हाँ! या "Add files" से

### Q: Changes कितने समय में reflect होंगे?
A: 1-2 मिनट

### Q: Custom domain कैसे लगाऊँ?
A: Domain खरीदो, फिर Settings → Pages → Custom domain
